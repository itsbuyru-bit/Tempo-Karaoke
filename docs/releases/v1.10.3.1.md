# Tempo Karaoke 1.10.3.1

Release date: 2026-11-07

## English

### Fixed

- Fixed a startup crash in the installed build: `MainPage.Connect` threw
  `InvalidCastException` while casting the search-empty hint to `TextBlock`.
  The hint is now updated through its parent panel instead of a generated
  `x:Name` field.
- The application starts normally again; no other changes were made to the
  search engine or remote UI in this patch.

## Русский

### Исправлено

- Исправлено падение установленной сборки при запуске: `MainPage.Connect`
  выбрасывал `InvalidCastException` при приведении подсказки пустого поиска к
  `TextBlock`. Теперь подсказка обновляется через родительскую панель, без
  сгенерированного поля `x:Name`.
- Приложение снова запускается нормально; других изменений в поисковом движке
  или веб-пульте в этом патче нет.
