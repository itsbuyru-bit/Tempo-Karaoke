# Tempo Karaoke 1.10.3.6

Release date: 2026-11-09

## English

### Changed

- Host and administrator PIN settings now use one password field per role
  instead of two confusing confirmation fields. Saving validates the entered
  PIN; an empty field keeps an existing PIN.
- The remote auto-stop interval is a plain minutes text field without spinner
  arrows. Invalid input is normalised to the 1–120 minute range on focus loss.
- The auto-stop field no longer takes focus while a PIN is being edited.

## Русский

### Изменено

- Для PIN ведущего и администратора теперь одно поле ввода на роль вместо двух
  запутанных полей подтверждения. При сохранении введённый PIN проверяется;
  пустое поле сохраняет существующий PIN.
- Интервал автоотключения пульта — обычное текстовое поле минут без стрелочек.
  Некорректный ввод нормализуется в диапазон 1–120 минут при потере фокуса.
- Поле автоотключения больше не получает фокус во время редактирования PIN.
