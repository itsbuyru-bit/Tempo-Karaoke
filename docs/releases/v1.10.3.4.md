# Tempo Karaoke 1.10.3.4

Release date: 2026-11-08

## English

### Fixed

- The update badge no longer stays on "New" after installing the latest
  release. Older settings stored a three-component version (`1.10.3`) while the
  installed app reports four (`1.10.3.3`); versions are now compared
  semantically.
- New update checks keep four-component versions in their status and pending
  settings.
- An explicit language choice is no longer overwritten when a catalog cannot be
  loaded temporarily. The saved language is preserved across updates.

## Русский

### Исправлено

- Плашка обновления больше не остаётся «Новое» после установки последней
  версии. В старых настройках хранилась версия из трёх компонентов (`1.10.3`),
  а установленное приложение сообщает четыре (`1.10.3.3`); теперь версии
  сравниваются семантически.
- Новые проверки сохраняют версию из четырёх компонентов в статусе и
  настройках ожидающего обновления.
- Явно выбранный язык больше не перезаписывается, если каталог перевода
  временно не загрузился. Выбор сохраняется между обновлениями.
