# Tempo Karaoke 1.10.3.8

Release date: 2026-11-21

## English

### Fixed

- The installed application no longer closes immediately after launch.
- The portable publish now includes `TempoKaraoke.pri` and the compiled `.xbf`
  files, so `MainWindow.InitializeComponent` can load the UI.
- `Assets/AppIcon.ico` is copied to the published output, so the window icon is
  available in unpackaged builds.

### Notes

- This fixes the `0xc000027b` / `Microsoft.UI.Xaml.dll` crash on startup that
  affected 1.10.3.7 installs.

## Русский

### Исправлено

- Установленное приложение больше не закрывается сразу после запуска.
- Портативная публикация теперь включает `TempoKaraoke.pri` и скомпилированные
  `.xbf`-файлы, поэтому `MainWindow.InitializeComponent` загружает интерфейс.
- `Assets/AppIcon.ico` копируется в опубликованный каталог, поэтому иконка окна
  доступна в unpackaged-сборке.

### Примечание

- Исправлено падение при запуске с кодом `0xc000027b` в
  `Microsoft.UI.Xaml.dll`, затронувшее установки 1.10.3.7.
