# Tempo Karaoke 1.10.3.7

Release date: 2026-11-09

## English

### Fixed

- Incomplete update downloads are removed before a retry; the `.part` file is
  deleted on every failed download.
- Cached installers are reused only when their size matches the GitHub asset;
  a corrupt or incomplete installer is discarded and downloaded again.
- A failed launch of the installer deletes the downloaded file; an update that
  is already installed clears the stale pending version and its installer.
- Old installers and partial downloads are pruned from
  `%LocalAppData%\TempoKaraoke\updates`.

## Русский

### Исправлено

- Недокачанные обновления удаляются перед повторной попыткой; `.part`-файл
  очищается при любой ошибке загрузки.
- Скачанный установщик переиспользуется только при совпадении размера с
  ассетом GitHub; повреждённый или неполный файл удаляется и скачивается заново.
- Если установщик не удалось запустить, скачанный файл удаляется; если версия
  уже установлена, устаревшая ожидающая версия и её установщик очищаются.
- Старые установщики и недокачанные файлы удаляются из
  `%LocalAppData%\TempoKaraoke\updates`.
