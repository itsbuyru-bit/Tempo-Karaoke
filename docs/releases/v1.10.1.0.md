## Новое

- **Полноценная проверка обновлений в «Параметры › Обновления».** Кнопка
  «Проверить обновления» запрашивает последний релиз на GitHub и показывает
  понятное состояние: идёт проверка (с индикатором загрузки и заблокированной
  кнопкой), установлена актуальная версия (зелёная галочка), доступно обновление
  (акцентный статус и кнопка «Установить vX») или ошибка подключения. До первой
  проверки показывается нейтральная подпись `Текущая версия: vX`.
- **Подтверждение установки.** Перед скачиванием установщика открывается диалог
  с версией и предупреждением, что приложение закроется; тема диалога совпадает
  с темой окна.
- **Локализация статусов на лету.** Все состояния обновлений берутся из
  `LocalizationService` и переключаются между русским и английским без
  перезапуска приложения.
- **Улучшения установщика Inno Setup:** вопрос об удалении данных переведён на
  русский и английский, кнопка «Нет» выбрана по умолчанию (защита от случайного
  удаления настроек), версия автоматически читается из `TempoKaraoke.exe`,
  добавлены ссылки GitHub в «Установка и удаление программ», дочерние процессы
  закрываются через `taskkill /t`, а маркер `install-scope.txt` удаляется при
  деинсталляции.
- **Тихий автостарт после обновления.** При запуске установщика из приложения
  (`/SILENT`) новая версия запускается автоматически, без финальной страницы
  мастера.

## Изменено

- Ошибка `404 Not Found` от GitHub (у репозитория нет релизов) считается
  состоянием «установлена актуальная версия», а не сетевым сбоем.
- Кнопка установки называется «Установить vX» (ранее «Обновить до vX»).
- Минимальная задержка проверки 400 мс: даже при мгновенном ответе сети видно,
  что проверка действительно выполнилась.

## Обновление

- Установщик `TempoKaraoke-Setup-1.10.1.0.exe` заменяет файлы и сохраняет
  настройки, очередь, плейлисты и кэш медиатеки.
- Миграция не требуется: схема `settings.json` не менялась.
