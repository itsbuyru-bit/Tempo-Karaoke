# Tempo Karaoke 1.10.3.0

Release date: 2026-11-07

## English

### Search engine

- Filename parsing now handles artist/title separators (`-`, `–`, `—`, `_`),
  leading and middle track numbers, reverse order, `feat`/`ft`/`&`/`vs`, and
  artist names in trailing `(Artist)` or `[Artist]` brackets.
- Technical tags such as `karaoke`, `минус`, `минусовка`, `live`, `бэк-вокал`,
  `1080p` and `4k` no longer hide the clean song title.
- The index now keeps the raw filename tokens, a Russian stem fallback, joined
  word pairs and phonetic keys alongside the normal title/artist fields.
- Search supports RU/EN transliteration, keyboard-layout correction,
  Damerau–Levenshtein typos, artist aliases, stop-word-free queries and an N−1
  fallback for long descriptions.
- Favorites, play counts, recency, artist intent and a diversity cap provide a
  predictable ranking without overriding exact textual matches.
- Search results are cached with an LRU cache that is invalidated by activity
  changes, and duplicate versions are grouped before QuickSearch/remote limits.

### Configuration

- `%LocalAppData%\TempoKaraoke\search_aliases.json` and
  `search_config.json` are created automatically when missing.
- External aliases and scoring thresholds are merged with safe built-in
  defaults; broken or missing files never break search.

### Web remote

- Mobile catalog cards give the title and artist the available width, wrap long
  names and keep the three actions as compact, consistent icon buttons.
- The language selector shows short codes (`EN`, `RU`, …) instead of long native
  names.
- Playlists show a loading row immediately, are prefetched after host sign-in
  and reused from a short-lived cache.
- The remote exposes search suggestions and a localized “refine your search”
  message when a query contains only stop words.

## Русский

### Поисковый движок

- Разбор имён файлов теперь понимает разделители `-`, `–`, `—`, `_`, номера
  треков в начале и середине имени, обратный порядок, `feat`/`ft`/`&`/`vs` и
  исполнителя в скобках `(Исполнитель)` или `[Исполнитель]`.
- Технические пометки `караоке`, `минус`, `минусовка`, `live`, `бэк-вокал`,
  `1080p`, `4k` больше не скрывают чистое название песни.
- В индексе хранятся исходные токены имени, стеммированные формы, склеенные
  пары слов и фонетические ключи.
- Поиск поддерживает транслитерацию RU/EN, исправление раскладки, опечатки по
  Дамерау–Левенштейну, алиасы исполнителей, удаление стоп-слов и мягкий
  fallback N−1 для длинных описаний.
- Избранное, количество запусков, свежесть, режим артиста и ограничение
  однообразия дают предсказуемое ранжирование, не перебивая точное совпадение.
- Результаты кэшируются LRU-кэшем с инвалидацией по активности, а версии одной
  песни группируются до лимитов быстрого поиска и веб-пульта.

### Конфигурация

- Файлы `%LocalAppData%\TempoKaraoke\search_aliases.json` и
  `search_config.json` создаются автоматически, если их нет.
- Внешние алиасы и пороги скоринга объединяются со встроенными значениями;
  повреждённый или отсутствующий файл не ломает поиск.

### Веб-пульт

- Мобильные карточки каталога отдают название и исполнителю всю доступную
  ширину, переносят длинные названия и используют три компактные одинаковые
  кнопки действий.
- В выборе языка показываются короткие коды (`EN`, `RU`, …), а не длинные
  названия.
- Плейлисты сразу показывают строку загрузки, предзагружаются после входа
  ведущего и переиспользуются из краткого кэша.
- Веб-пульт отдаёт подсказки поиска и локализованное сообщение «уточните
  запрос», если запрос состоит только из стоп-слов.
