# Tempo Karaoke 1.10.2.7

Release date: 2026-11-07

## English

### Distribution

- Tempo Karaoke is now distributed **only** through the Inno Setup installer.
- Removed the MSIX/AppX package manifest, package build/install/sign scripts,
  package-only logo assets and all Microsoft Store packaging instructions.
- User data always lives in `%LocalAppData%\TempoKaraoke`.
- The application is built with `WindowsPackageType=None`; updates are delivered
  by the existing silent Inno Setup updater.

### Reliability

- Single-instance handling now starts with a named Mutex instead of the
  AppLifecycle redirect. A second launch restores and focuses the existing
  window, then exits cleanly.
- Removed the AppLifecycle `RedirectActivationToAsync` path that could raise a
  native `CoreMessagingXP.dll` stowed exception (`0xc000027b`).

### Localization

- The installed `localization` folder is read at startup. Adding or editing
  `manifest.json` and a `<tag>.json` catalog there is picked up after an app
  restart; no rebuild is required for that installed copy.
- The web remote now serves the same installed localization folder, falling back
  to the generated `public/` files.
- `node scripts/localization/generate.mjs` is still required when preparing
  release artifacts (`.resw` and `public/` fallbacks).

### Documentation

- Packaging documentation is now Inno Setup-only.
- READMEs, privacy policy, contributing guide, feature guide, diagnostics and
  UX decisions no longer reference MSIX or Microsoft Store packaging.
- Translation contributions now have a bilingual pull-request template and a
  fast localization CI workflow that checks JSON, manifest, placeholders and
  generated artifacts.

## Русский

### Поставка

- Tempo Karaoke теперь распространяется **только** через установщик Inno Setup.
- Удалены манифест MSIX/AppX, скрипты сборки/установки/подписи пакета,
  логотипы, нужные только для пакета, и все инструкции по упаковке для
  Microsoft Store.
- Пользовательские данные всегда лежат в `%LocalAppData%\TempoKaraoke`.
- Приложение собирается с `WindowsPackageType=None`; обновления доставляет
  прежний тихий установщик Inno Setup.

### Надёжность

- Проверка единственного экземпляра теперь начинается с именованного Mutex, а не
  с редиректа AppLifecycle. Повторный запуск восстанавливает и выводит вперёд уже
  открытое окно и завершается с кодом `0`.
- Убран вызов `RedirectActivationToAsync`, который мог вызывать нативное
  stowed-исключение `CoreMessagingXP.dll` (`0xc000027b`).

### Локализация

- Установленная папка `localization` читается при старте. Если добавить или
  изменить в ней `manifest.json` и каталог `<tag>.json`, язык подхватится после
  перезапуска приложения — пересборка для установленной копии не нужна.
- Веб-пульт теперь тоже читает установленную папку `localization`, а
  сгенерированные файлы в `public/` используются как fallback.
- `node scripts/localization/generate.mjs` по-прежнему нужен при подготовке
  артефактов релиза (`.resw` и fallback-файлы в `public/`).

### Документация

- Документация по упаковке переписана только под Inno Setup.
- README, политика приватности, CONTRIBUTING, справочник возможностей,
  диагностика и UX-решения больше не ссылаются на MSIX и Microsoft Store.
- Для переводов добавлен двуязычный шаблон pull request и быстрый CI-workflow,
  который проверяет JSON, манифест, плейсхолдеры и сгенерированные артефакты.
