# Tempo Karaoke 1.10.4.1

Release date: 2026-11-21

## English

### Added

- Portable installation option in Setup: no shortcuts, registry entries, or
  uninstaller. Settings, queue, playlists, logs, and cache stay in `Data` next to
  the executable.
- A `Karaoke` folder next to the portable app is detected automatically as the
  library, so the same USB drive can be used on another PC.
- First portable launch can import settings, queue, and playlists from a regular
  installation; portable updates are installed back into the same folder.

### Fixed

- Startup crash `0xc000027b` in `Microsoft.UI.Xaml.dll` caused by missing
  `TempoKaraoke.pri` and `.xbf` files in the portable publish.
- Search tests now run without shared static-state races in CI.

## Русский

### Добавлено

- Пункт **«Портативная установка»** в установщике: без ярлыков, реестра и
  деинсталлятора. Настройки, очередь, плейлисты, логи и кэш хранятся в папке
  `Data` рядом с exe.
- Папка `Karaoke` рядом с портативным приложением автоматически определяется как
  библиотека — ту же флешку можно запустить на другом ПК.
- При первом запуске можно импортировать настройки, очередь и плейлисты из
  обычной установки; обновления ставятся обратно в ту же папку.

### Исправлено

- Падение при запуске `0xc000027b` в `Microsoft.UI.Xaml.dll` из-за отсутствующих
  `TempoKaraoke.pri` и `.xbf` в портативной публикации.
- Тесты поиска больше не зависят от гонок общего статического состояния в CI.
