# Tempo Karaoke 1.10.4.0

Release date: 2026-11-21

## English

### Added

- **Portable installation** option in Setup: install to a USB drive or any
  writable folder without shortcuts, registry entries, or an uninstaller.
- Portable builds keep settings, queue, playlists, logs, and cache in `Data`
  next to `TempoKaraoke.exe`.
- A `Karaoke` folder next to the app (or next to its parent folder) is detected
  automatically as the library location, so the same USB drive works on another
  PC.
- On the first portable launch, an existing regular installation can be asked to
  copy settings, queue, and playlists.
- Portable updates install back into the folder the app is running from.

### Fixed

- Startup crash of 1.10.3.7 caused by missing WinUI resource files in the
  portable publish.

## Русский

### Добавлено

- Пункт **«Портативная установка»** в установщике: установка на флешку или в
  любую доступную для записи папку без ярлыков, записей в реестре и
  деинсталлятора.
- Портативная версия хранит настройки, очередь, плейлисты, логи и кэш в папке
  `Data` рядом с `TempoKaraoke.exe`.
- Папка `Karaoke` рядом с приложением (или рядом с его родительской папкой)
  автоматически определяется как библиотека — флешку можно перенести на другой
  ПК.
- При первом запуске портативной версии можно скопировать настройки, очередь и
  плейлисты из обычной установки.
- Обновления портативной версии устанавливаются обратно в её текущую папку.

### Исправлено

- Падение при запуске 1.10.3.7 из-за отсутствующих ресурсов WinUI в
  портативной публикации.
