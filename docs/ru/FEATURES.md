# Tempo Karaoke — полный справочник возможностей

Tempo Karaoke — нативный караоке-плеер для Windows, работающий с локальными
видеоколлекциями. Он объединяет быстрый каталог, умный поиск, сохраняемую
очередь, плейлисты и веб-пульт для телефонов и планшетов. Медиатека не входит в
комплект поставки: приложение индексирует выбранные вами папки и никогда их не
изменяет.

## Системные требования

| Параметр | Требование |
|---|---|
| ОС | Windows 10 версии 1809 (сборка 17763) или новее, рекомендуется Windows 11 |
| Архитектура | x64 |
| Среда выполнения | Не нужна для портативного установщика — .NET и Windows App SDK включены |
| VLC | Не требуется; `libvlc` поставляется вместе с приложением |
| Диск | Около 110 МБ для установщика плюс место под медиатеку |

## Библиотека и индексирование

- Добавляйте любое количество папок с видео в **Параметры → Библиотеки**.
- Каждая папка сканируется рекурсивно. Индексируются только видеофайлы:
  `.mkv`, `.mp4`, `.avi`, `.mov`, `.webm`, `.m4v`, `.wmv`. Аудиофайлы вроде
  `.mp3` намеренно не попадают в каталог.
- Медиатека работает **только на чтение**. Tempo Karaoke не переименовывает,
  не перемещает и не удаляет исходные файлы.
- Кэш SQLite (`media.db`) хранит размер файла, время изменения, длительность,
  разрешение и пути к обложкам. Повторные запуски открываются мгновенно, а
  перечитываются только изменившиеся файлы.
- Скрытые папки и недоступные пути безопасно пропускаются; сканирование
  показывает прогресс и может быть отменено.
- В разделе **Все видео** доступны сортировка по названию или дате изменения,
  фильтр по папке и переключение между плоским каталогом и обзором папок.
- Дубликаты и разные версии одной песни группируются в одну карточку. Счётчик
  версий открывает список с папкой, форматом и размером.
- Карточка показывает название, длительность и превью, если его удалось
  извлечь.
- Фоновые обработчики метаданных и превью не блокируют прокрутку.

## Мгновенный умный поиск

- Поиск начинается по мере ввода и работает по индексу в оперативной памяти —
  без обращения к базе на каждое нажатие.
- Названия очищаются от технического мусора: тегов качества, кодеков,
  `[КАРАОКЕ]`, `[ТЕКСТ]`, подчёркиваний и повторяющихся разделителей.
- Транслитерация работает в обе стороны (кириллица ↔ латиница): `kishlak`
  находит `Кишлак`, и наоборот.
- Неверная раскладка клавиатуры исправляется автоматически.
- Нечёткий поиск терпит опечатки и частичные слова, а результаты сортируются по
  релевантности, а не только по алфавиту.
- Поиск охватывает текущую библиотеку и сохраняет группировку версий.
- `Ctrl+F` переводит фокус в глобальный поиск из любого раздела.

## Карточки, выделение и контекстные действия

- Двойной щелчок или кнопка **Воспроизвести** на карточке запускает песню.
- Кнопка **···** открывает меню карточки:
  - воспроизвести;
  - воспроизвести следующим;
  - добавить в очередь;
  - добавить в новый или существующий плейлист;
  - добавить в избранное / убрать из избранного;
  - свойства (кодек, разрешение, длительность, размер, путь);
  - выбрать.
- Правая кнопка мыши в любом месте карточки открывает то же меню у указателя.
- При наведении на карточку в левом верхнем углу появляется чек-бокс выбора, а
  также кнопки воспроизведения и «···». У уже выбранных карточек чек-бокс
  остаётся видимым, чтобы сетка не была загромождена постоянными флажками.
- Если выбрана одна или несколько карточек, над сеткой появляется панель:
  - количество выбранных;
  - очистить выделение;
  - воспроизвести выбранные следующими;
  - добавить выбранные в очередь;
  - добавить выбранные в плейлист;
  - выбрать все / снять выбор.
- Массовые действия сохраняют порядок карточек в текущем представлении.

## Воспроизведение

- Видео воспроизводится через **LibVLC** с аппаратным декодированием, если
  система его поддерживает.
- Поддерживаются контейнеры LibVLC: MKV, MP4, AVI, MOV, WebM, M4V, WMV и другие
  видеоформаты.
- Встроенные субтитры и караоке-текст отображаются плеером.
- Полноэкранный режим: `F11` или кнопка на панели; выход — `Esc`.
- Откреплённое окно видео: вынесите видео на второй монитор, проектор или
  телевизор, оставив панель управления на основном экране.
- Транспорт: воспроизведение/пауза, предыдущий, следующий, стоп, перемотка,
  громкость, без звука.
- Скорость воспроизведения: 0,5×, 0,75×, 1×, 1,25×, 1,5×.
- Десятиполосный эквалайзер с пресетами.
- Перемешивание и повтор: выключено, повтор всей очереди, повтор одного трека.
- Необязательный отсчёт перед следующим треком с настраиваемой длительностью.
- Последняя позиция запоминается и предлагается при повторном открытии файла.
- Недавние треки и избранное сохраняются локально.

## Очередь

- Добавляйте песни в очередь из карточек, поиска, папок, плейлистов или с
  веб-пульта.
- **Воспроизвести следующим** вставляет трек сразу после текущего.
- Перетаскивание меняет порядок; можно удалить отдельные треки или очистить
  очередь.
- Последнее удаление можно отменить.
- Режим выделения в очереди повторяет библиотеку: выбрать все, очистить,
  воспроизвести следующими, добавить в плейлист, удалить.
- Очередь сохраняется между перезапусками. Имена заказчиков сохраняются для
  песен, заказанных с веб-пульта.
- В очереди видны текущий трек, список следующих треков и общая длительность.

## Плейлисты

- Создание, переименование и удаление именованных плейлистов.
- Добавление треков из библиотеки, очереди, поиска или другого плейлиста.
- Перетаскивание меняет порядок треков.
- Плейлист можно воспроизвести сразу или добавить в текущую очередь.
- Импорт и экспорт в формате **M3U/M3U8**.
- Плейлисты хранятся локально в `playlists.json`.

## Веб-пульт для телефонов и планшетов

- Встроенный HTTP/WebSocket-сервер запускается в **Параметры → Веб-пульт** или
  из бокового меню.
- Подключение по QR-коду — устанавливать приложение на телефон не нужно.
- Работает по локальной сети Wi-Fi или через **Wi-Fi Direct** (прямое
  подключение без роутера).
- Роли:
  - **Гость** — поиск по каталогу, просмотр очереди, заказ песен.
  - **Ведущий** — вход по 4-значному PIN, управление воспроизведением,
    громкостью, порядком очереди, модерацией и пропуском треков.
  - **Администратор** — вход по PIN администратора для изменения настроек
    пульта.
- Пульт показывает текущий трек, состояние, позицию, длительность, очередь и
  следующие треки.
- Управление ведущего: воспроизведение/пауза, стоп, предыдущий, следующий,
  перемотка, громкость.
- Гости могут заказывать песни; лимит заказов на гостя и модерация настраиваются.
- Необязательная автоостановка после периода неактивности.
- Список подключённых устройств с именами и состоянием.
- PIN бывает временным (генерируется при каждом запуске) или постоянным.
  Хранятся только соль и хэш PBKDF2, сам PIN не сохраняется.
- Состояние пульта обновляется по WebSocket с автоматическим переподключением,
  keepalive-пингами и резервным опросом. После пробуждения телефона или смены
  сети страница обновляется сразу.
- Интерфейс пульта доступен на русском и английском.

## Параметры

Параметры организованы как каталог разделов:

- **Интерфейс** — язык (система, русский, английский), светлая/тёмная/системная
  тема, сброс положения окна.
- **Библиотеки** — добавление и удаление папок, повторное сканирование,
  просмотр проиндексированных файлов.
- **Воспроизведение** — отсчёт перед следующим треком и его длительность.
- **Веб-пульт** — сервер, QR-код, PIN, роли, автоостановка, Wi-Fi Direct,
  диагностика сети.
- **Безопасность** — PIN ведущего и администратора, постоянный PIN, состояние
  PIN.
- **Диагностика** — тайминги запуска, система и дисплеи, целостность настроек,
  логи и отчёты об ошибках.
- **Обновления** — текущая версия, ручная проверка, установка, заметки к релизу.
- **О приложении** — версия, ссылки, лицензии.

## Обновления

- Автоматическая проверка последнего релиза на GitHub раз в запуск (можно
  отключить).
- Ручная кнопка **Проверить обновления** в **Параметры → Обновления**:
  - индикатор загрузки и недоступная кнопка во время запроса;
  - состояние «актуальная версия» с зелёной галочкой;
  - состояние «доступна новая версия» с текущей и новой версиями;
  - понятное состояние ошибки сети.
- Автоматическая проверка показывает системный тост с переходом версий,
  размером, 1–2 пунктами changelog и датой публикации. Кнопки: **Установить**,
  **Позже**, **Что нового**. Клик по телу открывает **Параметры → Обновления**.
- Повторное уведомление заменяет предыдущее, а не складывается в стопку.
- Плашка у пункта «Параметры» показывает **Обновление** для доступной версии и
  **Новое**, когда установщик уже скачан. В свёрнутой панели акцентный значок
  появляется на шестерёнке.
- Перед установкой открывается подтверждение с предупреждением, что приложение
  закроется; установщик работает тихо и запускает новую версию, сохраняя
  настройки, очередь, плейлисты и кэш.
- Ответ `404 Not Found` от GitHub (релизов ещё нет) считается актуальной
  версией.

## Диагностика и надёжность

- Ротируемые локальные логи с настраиваемым ведением.
- ZIP-отчёт об ошибке в один клик с системными сведениями и маскированием
  приватных данных.
- Таймлайн запуска от старта процесса до интерактивного интерфейса.
- Диагностика дисплеев, DPI и положения окна.
- Проверка целостности `settings.json` и каталогов локализации.
- Диагностика сети и Wi-Fi Direct.
- Запись падений даже при отключённом обычном логировании.

## Локализация

- Русский и английский интерфейс с переключением без перезапуска.
- Список языков задаётся в `localization/manifest.json`; добавление языка не
  требует пересборки desktop-интерфейса.
- Desktop-файлы `.resw` и JSON веб-локалей генерируются из одного источника.
- Даты и числа форматируются по текущей культуре.
- Интерактивные элементы имеют доступные имена и поддержку клавиатуры.

## Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+F` | Фокус в глобальный поиск |
| `F11` | Полноэкранный режим |
| `Esc` | Выйти из полноэкранного режима |
| `Ctrl+I` | Информация о медиа |
| `Ctrl+E` | Эквалайзер |
| `Enter` | Воспроизвести выбранную карточку / трек очереди |

## Данные и приватность

- Данные хранятся в `%LocalAppData%\TempoKaraoke` (портативная сборка) или в
  `LocalState` пакета (MSIX):
  - `media.db` — метаданные проиндексированных файлов;
  - `settings.json` — настройки, положение окна, состояние обновлений;
  - `queue.json` — сохранённая очередь;
  - `playlists.json` — плейлисты;
  - `remote-clients.json` — авторизованные устройства пульта;
  - `activity.json` — избранное и история;
  - `logs/` — ротируемые логи;
  - `Reports/` — созданные пользователем ZIP-отчёты.
- Медиатека не изменяется, медиафайлы никуда не загружаются.
- Постоянные PIN хранятся как соль + хэш PBKDF2.
- Отчёты об ошибках маскируют приватные пути и имена узлов.
- Полная политика — в [PRIVACY.ru.md](../../PRIVACY.ru.md).

- **Портативная сборка + установщик Inno Setup** — установка в профиль
  пользователя без UAC по умолчанию; папку можно изменить; есть режим для всех
  пользователей.

  доставляет Windows/Store.
- Установщик удаляет только свои файлы; пользовательские данные по умолчанию
  сохраняются.
