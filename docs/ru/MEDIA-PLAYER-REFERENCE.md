# Microsoft Media Player — референс UI и кодеков

Дата осмотра: 2026-10-28.
Пакет: `Microsoft.ZuneMusic_11.2609.11.0_x64__8wekyb3d8bbwe`.
Приложение запущено и просмотрено через UI Automation; это **референс**, а не
копирование кода или ресурсов Microsoft.

## Что удалось посмотреть

- Главная: «Последние файлы мультимедиа», карточка папки `Karaoke`.
- Библиотека видео: вкладки «Все видео» / «Папки с видео», «Добавить папку»,
  «Воспроизвести все», сортировка «А–Я», сетка карточек с обложками.
- Очередь воспроизведения: текущий элемент подсвечен, длительность, «Очистить»,
  «Добавить в», список с drag-порядком.
- Now Playing: полноэкранный режим с кнопкой «Назад».
- Параметры: пути к библиотекам музыки и видео, обновление библиотек, тема,
  контрастность, поиск обложек в Интернете.

## Структура интерфейса

```
┌──────────────────────────────────────────────────────────────┐
│ Назад  Поиск                              Открыть файлы ▾    │
├───────────────┬──────────────────────────────────────────────┤
│ Главная       │  Заголовок страницы                          │
│ Музыка        │  Вкладки / фильтры / сортировка              │
│ Видео         │  Карточки или список                         │
│ Очередь       │                                              │
│ Плей-листы    │                                              │
│               │                                              │
│ Параметры     │                                              │
├───────────────┴──────────────────────────────────────────────┤
│ 00:00 ─────────●────────────────────────────── 03:23        │
│ [обложка] Название   ⤨  ⏮  −10  ▶  +30  ⏭  ⟳  ⧉  🔊  ⛶  ▣  … │
└──────────────────────────────────────────────────────────────┘
```

Ключевые элементы:

- левый `NavigationView` с разделами и настройками внизу;
- глобальный поиск в верхней панели;
- `SplitButton` «Открыть файлы» с дополнительными вариантами;
- нижняя панель now-playing: прогресс, обложка, название, shuffle, previous,
  skip −10 с, play/pause, skip +30 с, next, repeat, cast, volume, fullscreen,
  mini player, overflow;
- отдельная страница очереди, а не только боковая панель;
- полноэкранный Now Playing с минимальным управлением.

## Кодеки

Media Player **не тащит свои кодеки**: он использует Windows Media Foundation и
системные расширения. В зависимостях пакета только `Microsoft.UI.Xaml`,
.NET Native, VCLibs — кодеков там нет.

Установленные в системе расширения:

| Пакет | Версия |
|---|---|
| `Microsoft.HEVCVideoExtension` | 2.5.33.0 |
| `Microsoft.AV1VideoExtension` | 2.0.35.0 |
| `Microsoft.VP9VideoExtensions` | 1.2.20.0 |
| `Microsoft.MPEG2VideoExtension` | 1.2.32.0 |
| `Microsoft.WebMediaExtensions` | 2.1.51.0 |
| `Microsoft.AVCEncoderVideoExtension` | 1.1.47.0 |

Практический вывод:

- H.264/AAC, MP4 и MKV на Windows 10/11 обычно играются встроенным MF;
- HEVC, AV1, VP9, MPEG-2 доступны благодаря установленным расширениям;
- AC3/DTS и экзотика зависят от системных декодеров и могут не открыться;
- наш **libvlc** в главном окне несёт собственный ffmpeg и поддерживает больше
  форматов, чем MF;
- откреплённое окно сейчас на `MediaPlayerElement`/MF, поэтому его поддержка
  совпадает с системной, а не с libvlc.

## Что стоит перенять

1. **Нижняя панель now-playing**: обложка/кадр, название, прогресс, ±10/30 с,
   shuffle/repeat, громкость, fullscreen, mini player, overflow.
2. **NavigationView**: Главная, Библиотека видео, Очередь, Плей-листы, Настройки;
   настройки внизу, поиск сверху.
3. **Библиотека видео**: вкладки «Все видео» / «Папки с видео», «Добавить папку»,
   «Воспроизвести все», сортировка, карточки с превью.
4. **Очередь отдельной страницей**: текущий элемент, длительность, очистка,
   добавление в плейлист, перетаскивание.
5. **Now Playing**: полноэкранный режим с минимальным управлением и кнопкой назад.
6. **Mini player / compact overlay**: полезен, если свернуть караоке и продолжать
   управлять очередью.
7. **Языки и субтитры**, информация о медиа, overflow-меню.
8. **Параметры**: пути к библиотекам, обновление, тема, контрастность.
9. **Recent files / resume** и открытие файлов drag-and-drop.
10. **Keyboard/media keys**: play/pause, next/prev, seek, volume, fullscreen.

## Параметры (Settings)

Просмотрены разделы:

- «Пути к библиотеке музыки»;
- «Пути к библиотеке видео»;
- «Обновить библиотеки»;
- «Тема приложения»;
- «Контрастный цвет»;
- «Поиск недостающего изображения альбома и изображений автора в Интернете»
  (включён);
- «Медиаплеер» — служебный раздел приложения;
- «Справка» и «Отзывы и предложения».

Отдельных настроек видео/кодеков/декодера в интерфейсе нет: кодеки полностью
системные (Media Foundation + установленные расширения). Это подтверждает, что
копировать «настройки кодеков» из Медиаплеера нечего — можно перенять только
пути к библиотекам, обновление, тему, контрастность и онлайн-обложки.

## Шрифт иконок

В ресурсах приложения лежит `resources/fonts/MediaPlayerIcons.ttf` — фирменный
шрифт Microsoft. **Копировать его в Tempo Karaoke не нужно и не стоит**: это
чужой ресурс. Вместо него используются системные `Segoe Fluent Icons` через
`SymbolIcon`/`FontIcon` — те же по смыслу иконки (prev/next, play/pause, stop,
volume, fullscreen, detach, поиск, навигация), но без копирования proprietary
шрифта.


- иконки, обложки, шрифты и другие ресурсы Microsoft;
- XAML/код приложения;
- фирменные названия и оформление как «клон Медиаплеера».

Повторяем структуру и поведение средствами WinUI 3/Fluent, со своей визуальной
идентичностью Tempo Karaoke.

## Как это ложится на Tempo Karaoke

- Сейчас у нас три зоны: библиотека + плеер + очередь, снизу транспорт.
- Из Медиаплеера логично взять нижнюю панель now-playing, карточки/сетку,
  отдельную страницу очереди, полноэкранный Now Playing и mini player.
- NavView-вариант ближе к Медиаплееру, но очередь в караоке важнее, чем в
  обычном плеере; возможно, стоит оставить очередь всегда доступной.
- Кодеки: главный libvlc оставляем; откреплённое окно на MF — осознанный
  компромисс, при проблеме с кодеком возвращаем видео в главное окно.
